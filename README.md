## できること
- **バージョン聴き比べ**：同じ位置のまま切り替え、音量をそろえて公平に比較
- **音の診断**：LUFS・トゥルーピーク・音割れ・モノラル互換、配信サービスでの扱い
- **聞こえ方チェック**：スマホのスピーカー・安いイヤホン・車などの聞こえ方をまねる
- **お手本と比べる**：好きなプロの曲と音量をそろえて聴き比べ
- **歌詞を仕上げる**：タップで同期（行ごと・カラオケ式）、曲への埋め込み、字幕(.srt)書き出し
- **公開準備**：チェックリストとYouTube用の説明文
- **こだわりの音質**：10バンドEQ、出力先ごとの自動切替、ReplayGain、低音補強、夜間モードなど
- **動画とYouTube**：フォルダごとの連続再生、字幕、小窓再生

## インストール
1. 上のリンクから `KazuPlayer.apk` をダウンロードして開きます
2. 「この提供元のアプリを許可」をオンにしてインストールします（Android 11以降）

## プライバシー
アカウント・広告・利用状況の送信はありません。データはすべてスマホの中に保存されます。詳しくは紹介ページをご覧ください。
